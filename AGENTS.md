# DSI Studio AI control

The ai/ folder contains an AI-control-enabled DSI Studio installation.

When asked to operate DSI Studio:

1. Read `ai/DSI_STUDIO_AI_SETUP.md` completely and follow it.
2. Use its named-pipe connection to the already-running DSI Studio.
3. Verify completion and ask before destructive operations.
4. Do not modify this installation unless explicitly requested.
